From a host list
to an operations runbook.

Mark hosts, run a check, inspect each result, and keep repeatable work in Org.

Actual terminal output and keyboard input. Vertico and Marginalia are enabled. Two loopback SSH endpoints share one kernel; this is not a CyberArk deployment test.

What the recording shows

  1. M-x multihost, T, x: run a check on two marked hosts.
  2. RET, a, d: separate output, combined output, and digest.
  3. C-c C-c: execute an Org block serially in the selected host order.
  4. An intentional remote failure retains exit 7 and stderr.

Reproduce it

Requirements: Emacs, Python 3, OpenSSH client/server, and a non-root Linux account.

python3 tools/prepare-demo.py
python3 tools/demo.py
python3 -m http.server 8000

Open http://localhost:8000/docs/demo.html. Dependencies are pinned and checksum verified. The recording and player work offline after preparation.
