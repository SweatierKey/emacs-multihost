From a host list
to an operations runbook.

Retain SSH connections, complete remote filenames, run checks, and keep repeatable work in Org.

Actual terminal output and keyboard input. Vertico and Marginalia are enabled. Two loopback SSH endpoints share one kernel; this is not a CyberArk deployment test.

What the recording shows

  1. M-x multihost, T, w, C: initialize two SSH connections and inspect retained workers.
  2. x: run a check on both marked hosts using the connection pool.
  3. RET, a, d: separate output, combined output, and digest.
  4. M-x multihost-org-completion-enable, M-TAB: remote filename completion with host annotations, also inside C-c '.
  5. C-c C-c: execute an Org block serially in the selected host order.
  6. An intentional remote failure retains exit 7 and stderr.

Reproduce it

Requirements: Emacs, Python 3, OpenSSH client/server, and a non-root Linux account.

python3 tools/prepare-demo.py
python3 tools/demo.py
python3 -m http.server 8000

Open http://localhost:8000/docs/demo.html. Dependencies are pinned and checksum verified. The recording and player work offline after preparation.
